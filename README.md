# 🎵 Spotify Clone

A **pixel-perfect recreation of the Spotify Web Player interface**, built entirely with **HTML and CSS**.

This project was created to strengthen frontend development skills by recreating Spotify's desktop interface from scratch, with a focus on **CSS Flexbox, Grid, responsive layouts, positioning, and dynamic viewport calculations**.

## ✨ Features

* 🎧 Spotify-inspired Web Player interface
* 📱 Responsive layout
* 🧱 CSS Flexbox-based layouts
* 🔲 CSS Grid for structured content sections
* 🎨 Dark-themed Spotify-style UI
* 📐 Dynamic viewport height calculations
* 🎵 Sidebar navigation
* 🏠 Home and library sections
* 🎶 Music cards and playlist sections
* 🎛️ Bottom music player interface
* 🔊 Playback controls UI
* ❤️ Like/favorite interface ele
